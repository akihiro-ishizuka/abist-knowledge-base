# 議事録から恒久知識を起こす

## なぜ必要か

このナレッジベースは **議事録が 3,081件で全体の 89%** を占めます（索引 3,467件中・`document_type` 別の実測）。
決定事項・手順・設計判断が議事録の中に埋もれていて、後から探しにくい状態です。

議事録は「いつ何を話したか」の記録であって、「今どうなっているか」を答えるものではありません。
検索で議事録が上位に来ても、**それが現在も有効な決定なのか分からない**という問題があります。

このスキルは、議事録に埋もれた恒久的に有効な内容を拾い出し、独立した知識文書の草案を作ります。

## 原則

**草案までしか作らない。** 恒久知識として登録するかは人間が決めます。
議事録の内容が現在も有効かは、その場にいた人にしか判断できません。

**元の議事録を書き換えない。** 議事録は当時の記録として残します。

## 手順

### 1. 対象を絞る

```
search_kb(query: "...", document_type: "meeting", path_prefix: "チーム内定例/議事録/設計効率化/三桜工業様定例")
```

案件・期間で絞ってください。全議事録を対象にすると量が多すぎて精度が落ちます。

### 2. 恒久知識になる内容を拾う

議事録の中で次に当たるものを探します。

| 拾う | 拾わない |
| --- | --- |
| 決定事項（「◯◯方式で行く」） | 検討中・保留の話題 |
| 設計判断とその理由 | 日程調整・出欠 |
| 手順・運用ルール | 進捗報告の数値 |
| 制約・前提条件 | 次回の予定 |
| 不具合の原因と対処 | 個人の作業状況 |

**理由が書かれているものを優先します。** 「◯◯にした」だけより「△△だから◯◯にした」の方が、
後から読んで判断の再利用ができます。

### 3. 同じ話題の議事録を集める

一つの決定は複数回の議事録にまたがることが多いです。同じ話題を追ってください。

```
search_kb(query: "決定事項のキーワード", document_type: "meeting")
```

**時系列で並べて、最後の決定を採用します。** 途中で方針が変わっていることがあります。
変遷自体が重要なら「経緯」として残してください。

### 4. 草案を書く

```markdown
---
source: manual
managed_by: human
document_type: knowledge
status: active
---

# （何についての知識か）

## 結論

（今どうなっているか。1〜3行）

## 経緯

（なぜそうなったか。判断の理由）

## 出典

- [2026_07_23_三桜工業様定例](docs/.../2026_07_23_三桜工業様定例.md#L45-L60)（esa #5170 / 2026-07-23）
- [2026_07_09_三桜工業様定例](docs/.../2026_07_09_三桜工業様定例.md#L12-L28)（esa #5120 / 2026-07-09）
```

**出典は必ず行番号まで書きます。** 後から「本当にそう決まったのか」を確認できるようにするためです。

`document_type: knowledge` と `managed_by: human` を付けてください。
これで自動同期の対象外になり、esa 由来の議事録とは別に管理されます。

### 5. 人間のレビューに出す

草案を提示して、次を確認してもらいます。

- **今も有効か** — 決定が後で覆っていないか
- **抜けが無いか** — 前提条件や例外が落ちていないか
- **粒度が適切か** — 細かすぎる／大きすぎる

**レビュー前に `docs/` へ保存しないでください。** 未確認の内容が検索に載ると、
出典付きで間違った回答を返す原因になります。

## 保存先

レビューを通ったら、案件のフォルダ配下に置きます。

```
docs/チーム内定例/設計効率化/三桜工業様/蛇腹形状の自動設計/知識/（タイトル）.md
```

esa に載せる場合は `managing-esa-posts` スキルを使ってください。
esa 側に作れば次回の同期で `source: esa` として取り込まれ、以降は esa が正本になります。

## やってはいけないこと

- **議事録に書かれていないことを補わない。** 分かった気になって一般論を足すと、出典と内容が食い違います
- **複数の決定を1文書に詰め込まない。** 探しにくくなります。話題ごとに分けてください
- **元の議事録を編集しない。** 当時の記録として残します
